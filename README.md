# Portfolio — Muhammad Amjad

Personal portfolio for my freelance work: AI agents, chatbots, automations, CRM integrations and AI-powered applications.

Built with Next.js 16 (App Router), React 19, TypeScript and Tailwind CSS v4.

## Getting started

Requires Node.js 20+ and pnpm.

```bash
pnpm install
pnpm dev      # http://localhost:3000
pnpm build    # production build
pnpm lint
```
